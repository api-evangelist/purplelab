## Products

- **HealthNexus** — the multimodal no-code analytics platform. Six capabilities: Research, Analyze,
  Segment, Activate, Measure, Optimize. https://purplelab.com/platform
- **CLEAR RWD** — the enriched, research-ready dataset behind the platform: medical and pharmacy
  claims harmonized into a unified data model, clinically validated concept groups, SDOH attributes,
  mortality data, and provider hierarchies. PurpleLab states CLEAR Claims Data is certified to
  HIPAA's de-identification standard under the Expert Determination method (45 CFR 164.514(b)(1)).
- **HealthNexus API Streams** — subscription-based pre-built data feeds and scoring APIs intended to
  augment a customer's own datasets. PurpleLab has marketed streams covering Provider Profiles,
  Provider Locations, Provider Migrations, Provider Credentials, Provider Qualifications, Provider
  Experience, Provider Practice Characteristics, Provider Affiliations, Industry Influence, Payer
  Influence, Provider Performance Scores, Provider Efficiency, Patient Risk Adjustment Factor and
  Patient SDOH. The dedicated product page has been retired — `/api-streams/` and
  `/healthnexus-streams-api/` both return 404 as of 2026-08-26 — and API Streams is now referenced
  only in passing on the platform page.

## Who it serves

Life sciences, advertising agencies and media, financial services, healthcare payers, and providers.

## Access modes

No-code analytics in the platform, parameterized queries, custom data extracts, direct data delivery
into the customer's own environment, and subscription API data feeds. All commercial and gated.

## API hosts (probed, not documented)

- `https://api.purplelab.com` — live first-party JSON API host. Root returns HTTP 200
  `{}`; unknown paths return a bespoke JSON 404 envelope. No routes are published.
- `https://api.healthnexus.io` — AWS API Gateway fronting the HealthNexus platform. Returns HTTP 403
  `{"message":"Forbidden"}` to every anonymous request. `https://portal.purplelab.com/` 307-redirects
  to `https://api.healthnexus.io/healthnexussso/checklogin`, which is how this host was identified as
  PurpleLab's.

## Authentication

Bespoke first-party SSO (HealthNexus SSO) fronted by AWS API Gateway. Undocumented publicly; no

## Compliance

- HIPAA de-identification, Expert Determination method (45 CFR 164.514(b)(1)) — certified by
  qualified expert statisticians per PurpleLab's product privacy policy.
- CCPA consumer rights, served through a OneTrust privacy-choices webform.
